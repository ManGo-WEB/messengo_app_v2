# Единый кабинет — UI-прототип на React

Интерактивный UI-прототип омниканального сервиса общения (WhatsApp, Telegram, VK,
Instagram, Avito и др. в одном окне), спроектированный по референсам Umnico.
Готовая компонентная база для начала разработки на React.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production-сборка в dist/
```

## Что внутри

| Раздел | Страница | Интерактив |
|---|---|---|
| Чаты | Список диалогов (Новые / Принятые / Архив), фильтры, поиск, таблица | Клик по строке открывает панель переписки, отправка сообщений (Enter) |
| Каналы связи | Подключённые каналы + сетка доступных к подключению | Кнопка «Перейти к оплате» ведёт в Оплаты |
| Оплаты | Тарифная сетка, карточка «Мой тариф» | Переключение периода (скидки 10/35/50%), клик по плитке добавляет/убирает канал, степперы количества, живой пересчёт суммы и даты окончания |
| Воронка | Kanban по этапам сделки | Drag & drop карточек между колонками (HTML5 DnD) |
| Задачи | Календарь месяц/неделя/день | Навигация по месяцам, кнопка «Сегодня», счётчики статусов |
| Настройки | Профиль / Уведомления | Переключатели |

Посетители, Аналитика и Инструменты — заглушки в навигации.

## Структура

```
src/
  styles/
    tokens.css        # дизайн-токены: цвета, радиусы, тени, шрифт — вся тема в одном месте
    base.css          # reset + каркас (сайдбар + контент)
  data/mock.js        # мок-данные (диалоги, каталог каналов с ценами, сделки, задачи)
  lib/util.js         # форматирование денег и дат
  components/
    icons/Icon.jsx           # UI-иконки (stroke-SVG, 24×24, currentColor)
    icons/ChannelIcon.jsx    # круглые бренд-иконки мессенджеров (+ mono-вариант)
    ui/ui.jsx + ui.css       # примитивы: Button, Badge, Tabs, Toggle, Stepper,
                             # Checkbox, SearchInput, FilterChip, InfoBanner, Avatar
    layout/Sidebar.jsx       # тёмная боковая навигация
    layout/TrialBanner.jsx   # красный баннер «Пробный период закончился»
  pages/
    InboxPage.jsx / ChatPanel.jsx    # два-pane: список диалогов + переписка
    ChannelsPage.jsx
    PaymentsPage.jsx
    SettingsPage.jsx
    BoardPage.jsx                    # kanban с drag&drop
    CalendarPage.jsx
  App.jsx             # переключение страниц (состояние; при росте — react-router)
```

## Как адаптировать под свой продукт

- **Брендинг и цвета** — правьте `tokens.css`: `--accent` (основной синий),
  `--sidebar-bg`, смысловые цвета, радиусы. Весь UI перекрашивается автоматически.
- **Каналы** — список мессенджеров и цены в `data/mock.js` (`CATALOG`, `CONNECTABLE`).
  Иконки каналов — в `ChannelIcon.jsx` (`BRANDS`: цвет/текст/глиф), алиасы продуктов
  одного мессенджера — в `ALIASES`.
- **Ширина макета** — `.content` в `base.css`: узкие страницы ограничены 1160px,
  «рабочие» (Чаты, Воронка, Задачи) — 1720px; оба контейнера центрируются
  (`margin: 0 auto`), поэтому на 2K/4K нет пустоты только с одной стороны.
- **Шрифт** — по умолчанию системный стек; для фирменного шрифта подключите его в
  `index.html` и укажите в `--font`.
- **Роутинг** — сейчас `useState` в `App.jsx`; при подключении API замените на
  react-router, страницы менять не нужно.
- **Данные** — все страницы читают `data/mock.js`; точки интеграции с API очевидны
  (каждая страница — один хук с загрузкой вместо импорта мока).

## Адаптивность

- **Широкие экраны (1920 / 2K / 4K)** — весь контент центрируется: контентные
  страницы в колонке 1160px, рабочие — до 1720px. Пространство делится поровну
  слева и справа.
- **Ноутбуки (1280–1536)** — макеты дышат: сетки каналов и тарифов построены на
  `auto-fill/minmax` и перестраиваются с 4–5 колонок до 3.
- **Уже ≤1080–1100px** — карточка «Мой тариф» уходит под тарифную сетку; таблица
  диалогов и календарь прокручиваются по горизонтали как единое целое; тулбары
  имеют собственную горизонтальную прокрутку.
- Ориентир прототипа — десктоп (от ~1024px); мобильная версия (сайдбар-бургер,
  карточки вместо таблиц) — отдельная задача.

## Принятые дизайн-решения (по референсам Umnico)

- Тёмный сайдбар 78px с активным пунктом-«квадратом» акцентного цвета.
- Контентные колонки 1160/1720px по центру, карточки с радиусом 14px и тонкой
  границей вместо теней.
- Статусы — мягкие плашки (red-soft / green-soft), «Free» — зелёная капсула.
- Тарифная сетка: неподключённые каналы — серо-голубые (mono), выбранные — цветные
  с синей рамкой; период выбирается «капсулой», скидка подсвечена жёлтым.
- В дорожной карте прототипа не было: тёмная тема, мобильная адаптация,
  реальные выпадающие списки фильтров.
