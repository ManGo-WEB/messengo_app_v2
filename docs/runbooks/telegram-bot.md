# Runbook: Telegram-бот (B2)

Статус: **🖥 серверная приёмка** — `setWebhook` требует публичный URL; локально
канал проверяется интеграционным тестом на фикстурах (`tests/integration/telegram-bot.test.ts`).

## 1. Создание бота (делает владелец/оператор)

1. В Telegram написать [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Указать имя и username бота (например, `myshop_support_bot`).
3. Скопировать **токен** вида `123456789:AA...` (Manage bot → API Token).

## 2. (Опционально) Канал со связанной группой обсуждения — для комментариев

1. Создать канал (или использовать существующий).
2. В настройках канала включить **Обсуждения** и создать/выбрать связанную группу —
   она станет группой комментариев.
3. Добавить бота в канал **администратором** с правом **публиковать сообщения**,
   и в связанную группу — администратором.
4. В форме подключения указать username канала (например, `@mynews`).

## 3. Подключение (оператор в UI)

`POST /api/channels/telegram-bot/connect` с телом `{ token, channelUsername? }`:

1. Проверка токена: `getMe` (бот, id совпадает с префиксом токена — как в V1);
   некорректный токен → 400 `TELEGRAM_INVALID_TOKEN`.
2. При `channelUsername`: `getChat` канала → тип `channel` + `linked_chat_id`
   связанной группы; бот — администратор канала (can_post_messages) и группы;
   иначе понятные ошибки (`TELEGRAM_NOT_CHANNEL`, `TELEGRAM_DISCUSSION_REQUIRED`,
   `TELEGRAM_ACCESS_DENIED`).
3. `setWebhook` на `https://<домен>/api/webhooks/telegram` c `secret_token`
   (генерируется сервером, вид `<connectionId>.<random>`) и `allowed_updates`.
4. Подключение → **ACTIVE**; токен и секрет вебхука хранятся зашифрованными
   (`ChannelConnection.config`).

## 4. Работа канала

- **Личка**: каждый чат с ботом = диалог (`dm:<chatId>`), каждое обсуждение
  под постом канала = отдельный диалог-ветка (`post:<postId>`, threadTitle = начало поста).
- **Ответ оператора**: `sendMessage` (личка) или `sendMessage` c `reply_parameters`
  в группу обсуждения (комментарий под постом) — тонкий клиент на fetch, без
  telegram-библиотек (как в V1).
- **Отключение**: `DELETE /api/channels/telegram-bot/:id` — `deleteWebhook`,
  статус DISCONNECTED, секреты затираются.

## 5. Переменные окружения

Отдельные переменные не нужны: URL вебхука — `TELEGRAM_WEBHOOK_URL` (опционально)
или `${AUTH_BASE_URL}/api/webhooks/telegram`.

## 6. Ограничения (наследуются из Telegram)

- Бот не может писать первым в личку (только ответ в течение… ограничений нет,
  но пользователь должен начать диалог сам).
- Комментарии отправляются ответом на пост (`reply_parameters`), поэтому
  «свежесть» поста ограничений не имеет, но удалённый пост → ошибка отправки.
- 429 (flood control) → повторная попытка воркером с экспоненциальной задержкой.
